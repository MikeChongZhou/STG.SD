# Screen Time Guardian 1.1.7

## Highlights

- Weekly OpenRouter trends now choose the latest completed week's Top 10 independently for the selected metric, including revenue and prices.
- macOS reports use a compact bitmap-first layout and a single system calendar date picker.
- Windows reports use denser date and bitmap headings, and tray double-click reopens the main window.
- macOS menu-bar double-click reopens the main window; the app also appears in the Dock and Command-Tab switcher.
- Test-log export is consistently located in Settings on all four platforms.
- Android test logs now include lifecycle, minute samples, meeting decisions, reports, tracking, reminders, and sync results.
- iOS Settings no longer exposes estimate-reset or imported-device deletion shortcuts.

All four applications report version 1.1.7. Android remains compatible with Android 7.1.1 (API 25) and later.

# Screen Time Guardian for Windows 1.1.3

- Fits every WPF window to the current monitor's usable work area using its actual per-monitor DPI.
- Keeps Settings actions visible in a fixed footer while only the content area scrolls.
- Reduces oversized default window dimensions and improves proportions on laptop displays.
- Reflows private-cloud account controls when horizontal space is limited.
- Makes report actions wrap safely and allows minute bitmaps to scale down without clipping.
- Refines cards, spacing, typography, buttons, and compact dialogs for a more consistent visual hierarchy.

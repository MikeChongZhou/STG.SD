# Windows build

Download [ScreenTimeGuardian-windows-x64-1.2.28.zip](ScreenTimeGuardian-windows-x64-1.2.28.zip), extract the full folder, and run `ScreenTimeGuardian.exe`.

This build requires the [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0/runtime). Keep the extracted files together. The included `Uninstall Screen Time Guardian.cmd` removes the app's startup entry and offers to keep or delete local settings and usage data.
